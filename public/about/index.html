About Free Currency Converter

Free Currency Converter is a free browser tool to convert 140+ world currencies with emphasis on African markets: RWF, CDF, XOF, XAF, KES, UGX, and TZS versus USD and EUR.

Open-source base

The converter UI is based on SeyyidKadir/fx-currency-converter. The original README grants MIT terms (no separate LICENSE file in that repository). We added a full MIT LICENSE in this project and credit SeyyidKadir in the footer.

Exchange rate data

Default data comes from open.er-api.com (no API key). If that endpoint fails, we automatically fall back to Fawaz Ahmed currency-api on jsDelivr, then pages.dev.

Rates are indicative only and may differ from your bank or mobile-money provider.
