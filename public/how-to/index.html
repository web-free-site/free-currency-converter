How to convert currencies

  1. Enter an amount.
  2. Choose source and target currencies (e.g. RWF → USD).
  3. Keep Open ER API selected for the default feed with automatic Fawaz fallback.
  4. Click Convert. Results use live rates cached for your session until you refresh.
